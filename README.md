## 🎨 Design Philosophy & Features

All presentations are custom-built following [`SLIDE_DESIGN_GUIDELINES.md`](./SLIDE_DESIGN_GUIDELINES.md):
- **16:9 Canvas Stage**: Auto-scaling presentation viewport optimized for university projectors and lecture hall screens.
- **Institutional Branding**: AUPP official colors (Navy `#0D1F3C`, Crimson `#C8102E`, Bull Green `#00A868`, Gold `#D97706`).
- **Interactive Demonstrations**: Embedded SVG charts, candle toggle views, and dynamic math/position-sizing calculators.
- **Presenter Controls**:
  - `→` / `Space` / `PageDown` / `J`: Next slide
  - `←` / `PageUp` / `K`: Previous slide
  - `F`: Toggle full-screen mode
  - `G`: Slide overview grid modal (jump to any slide)
  - `P` / `Cmd+P`: Export to PDF
